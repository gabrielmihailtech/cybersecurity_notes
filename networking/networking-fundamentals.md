# Networks
Networks are systems of interconnected devices that communicate with each other.

Ex: A group of friends or a company with minimum 2 people.

# Internet
The Internet is a global network of interconnected networks.

Ex: A company that have a few departments or a few branches inside.

# IP Addresses
IP Address (Internet Protocol Address) is associated as person name, to identify a device.

Right now we have 2 types of IP addresses: IPv4 ex: 192.168.1.1 and IPv6 ex: 2a00:1531:cce6::f64d:321::c500

# MAC Addresses
MAC(Media Access Control) address is considered as an "ID" for a "name" in a network, ex: b3:f9:ac:91:2a:30.
First 6 characters represent the vendor and the last 6 characters is a unique number.
MAC addresses can be "spoofed" in a process known as spoofing, that means an attacker can pretend is identifying as another MAC address in order to get information from another sender.

# Ping
ping- is checking if my IP address can connect with that IP address, ex: ping 192.168.1.254
Ping use this protocol: (ICMP)- Internet Control Message Protocol
