# Lab 07 - Users and Groups

Commands:

- whoami
- id
- groups
- cat /etc/passwd

Learned:

- whoami shows current user
- id shows UID, GID and group membership
- groups shows user groups
- /etc/passwd contains system users
- root is the Linux administrator account

Observed Groups:

- adm
- cdrom
- sudo
- dip
- plugdev
- users

Examples:

whoami

id

groups

cat /etc/passwd | head

Important Users:

- root
- daemon
- bin
