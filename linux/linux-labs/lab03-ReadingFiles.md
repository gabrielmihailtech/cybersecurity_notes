# Lab 03 - Reading Files

Commands:

- cat
- head
- tail
- less

Created:

- auth.log

Learned:

- cat displays entire file content
- head displays first 10 lines
- tail displays last 10 lines
- less is useful for large files
- q exits less

Examples:

cat auth.log

head auth.log

tail auth.log

less auth.log

echo "Failed password for admin from 10.0.0.1" >> auth.log
